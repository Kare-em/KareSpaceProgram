# Состояние проекта (детально, на 02.10.2026)

Краткая версия — в `CLAUDE.md`. Здесь — что уже сделано.

## Ядро (M0)
Эфемериды, Кеплер, patched conics, атмосфера СА-1976, RK4, ступени, двигатели (запуски, ullage), автопилоты выведения /
исполнения узла / посадки, окна старта, планировщик перелёта, миссии. Тесты ✅ (24 группы) включая полный прогон «Луна-9»:
старт → орбита → перелёт → мягкая посадка 3,3 м/с.

## Игровой слой
- Сцена `Scenes/Flight.unity` собирается меню **Kare/Build Flight Scene** (идемпотентно). Миссия по умолчанию —
  `GameBootstrap.MissionId = "vostok"`. Ввод — старый Input Manager (Input System нет).
- HUD v2: иконки, стек ступеней, режим автопилота; H — подробная телеметрия.
- Стартовый стол с фермами (`LaunchPadView`, отвод по отрыву), грунт патча (тайл в метрах + детальная карта),
  камера кадрирует борт с факелом.
- Земля: биомы `EarthSurface` (температура + влажность), блик океана маской, облака отдельной сферой +8 км, вблизи —
  вода патча (нормаль Car_Train, снос ряби) и дно до −200 м. Старт: текстура Земли 2048 ≈ 2,3 с, облака ≈ 0,45 с.
- Парашют в `VesselView`, меню Esc (`PauseMenu`), на карте метки за планетой полупрозрачны (`MapView.Occluded`).
- Свет (02.10.2026): блик Солнца — lens flare SRP (`SunFlare`), ночь — отражённый свет Луны/Земли и свечение неба
  (`NightLight`), EvMin −7. RT-тени Солнца и DLSS (`RenderQuality`), смещение дальнего RT-луча 50 м
  (`SkyController.DistantRayBias`). Котловина космодрома `LaunchSite.BasinRadius` 150 км без озёр.
- Детали из Blender (`Models/*.fbx`, поля `GameBootstrap`): СА «Восток», приборный отсек с ТДУ, ПС-1, станция Е-6,
  блоки РД-107, РД-0110 верхней ступени, ферма горячего разделения (корпус нижней ступени короче на её высоту),
  створки обтекателя, хвост Г-1 со стабилизаторами, опоры, фермы стола. Модель секции — `SectionDef.Model`.
- Аппараты в натуральную величину (03.10.2026, `GameBootstrap.CraftMeshes`, масштаб 1, свои сопла и опоры):
  Луноход-1, КТ «Луны-17», LM (посадочная/взлётная), КМ и СМ «Аполлона», «Меркурий», «Джемини» + адаптер,
  «Сервейор», «Рейнджер», «Эксплорер-1». Палитра по слотам — `VesselView.CraftPalette`.

## Манёвры
`NodePlanner`; клавиши N (узел; повтор — следующая опорная точка) / B (исполнить/прервать) / Bksp (удалить) /
C (круговая), I-K / L-J / O-U — Δv по осям, `[ ]` — сдвиг по времени, Alt — мелкий шаг.

  `SectionDef.FinArea`).
