## Игровой слой
- Сцена `Scenes/Flight.unity` собирается меню **Kare/Build Flight Scene** (идемпотентно). Миссия по умолчанию —
  `GameBootstrap.MissionId = "vostok"`. Ввод — старый Input Manager (Input System нет).
- HUD v2: иконки, стек ступеней, режим автопилота; H — подробная телеметрия.
- Стартовый стол с фермами (`LaunchPadView`, отвод по отрыву), грунт патча (тайл в метрах + детальная карта),
  камера кадрирует борт с факелом.
- Земля: биомы `EarthSurface` (температура + влажность), блик океана маской, облака отдельной сферой +8 км, вблизи —
  вода патча (нормаль Car_Train, снос ряби) и дно до −200 м. Старт: текстура Земли 2048 ≈ 2,3 с, облака ≈ 0,45 с.
- Парашют в `VesselView`, меню Esc (`PauseMenu`), на карте метки за планетой полупрозрачны (`MapView.Occluded`).
- Свет (02.10.2026): блик Солнца — lens flare SRP (`SunFlare`), ночь — отражённый свет Луны/Земли и свечение неба
  (`NightLight`), EvMin −7. RT-тени Солнца и DLSS (`RenderQuality`), смещение дальнего RT-луча 50 м
  (`SkyController.DistantRayBias`). Котловина космодрома `LaunchSite.BasinRadius` 150 км без озёр.
- Детали из Blender (`Models/*.fbx`, поля `GameBootstrap`): СА «Восток», приборный отсек с ТДУ, ПС-1, станция Е-6,
  блоки РД-107, РД-0110 верхней ступени, ферма горячего разделения (корпус нижней ступени короче на её высоту),
  створки обтекателя, хвост Г-1 со стабилизаторами, опоры, фермы стола. Модель секции — `SectionDef.Model`.
- Аппараты в натуральную величину (03.10.2026, `GameBootstrap.CraftMeshes`, масштаб 1, свои сопла и опоры):
  Луноход-1, КТ «Луны-17», LM (посадочная/взлётная), КМ и СМ «Аполлона», «Меркурий», «Джемини» + адаптер,
  «Сервейор», «Рейнджер», «Эксплорер-1». Палитра по слотам — `VesselView.CraftPalette`.

## Автопилоты и клавиши (03.10.2026)
G — выведение на 200 км (с безатмосферного тела при цели стыковки — 30 км в её плоскость), на орбите без атмосферы —
посадка. **Y — автопилот всей миссии** (`Core/Flight/MissionAutopilot.cs`: сценарий по целям миссии — выведение,
витки, сход, перелёт к Луне, торможение, посадка, взлёт, стыковка, возврат и вход; сам ведёт ускорение времени —
`Universe.AutoWarp`, галка в Esc «Автопилот сам управляет ускорением»; при выходе из автопилота — ×1). Все 16 миссий
проходятся без рук (тест `auto`). R — старый «к Луне» (`LunarAutopilot`: опорная орбита, разгон с прицелом по
перицентру, перестроение, коррекция, торможение, доводка `Trim`). **P — манёвр к цели с авторасчётом**
(`Core/Flight/ManeuverAutoPlan.cs`): цель — тело в фокусе карты (M, Tab), иначе Луна с Земли / Земля с Луны;
спутник — `PlanIntercept` + доводка перицентра 100 км по прогнозу, родитель — `PlanReturn` (коридор входа 45 км),
соседняя планета — `PlanInterplanetary` (Ламберт). Только ставит узел, исполняет B (тест `autoplan`).
**Тутор после выведения** — `Core/Missions/MissionGuide.cs` (панель «шаг — что нажать» в `FlightHud.Guide`, галка
«Подсказки по полёту» в Esc): узел, взлёт, спуск, орбита, сход, коррекция входа, разгон к Луне, перелёт, возврат.
Карта (M): орбиты тел из списка фокуса, траектория корабля на 6 участков с переходами SOI, другие корабли (△). V — сближение и стыковка с ближайшей целью. Тутор (`FlightHud.Tutor`) ведёт по закону
`AscentAutopilot.GuidedSin`; отсечку предлагает только при наличии перезапуска.
Esc: «Бесконечное топливо», «Бесконечные перезапуски двигателей» (`Vessel.UnlimitedIgnitions`), ползунки яркости
(`BrightnessSettings`: общая яркость `Ev` и яркость факела `Plume`, хранятся в PlayerPrefs).

## Стартовые комплексы (03.10.2026, `Game/LaunchPadView.cs`, `Tools/blender/launch_pads.py`)
Свой стол у семейства первой секции (`SectionModel` → комплекс): Sputnik/Vostok/Luna/прочее → Р-7 (4 фермы «тюльпан», две
наклонные мачты, лоток); ProtonStage1 → Протон (кольцо на 6 опорах, высокая мачта, ферма откачена); Redstone, JunoStage1 →
малый стол на 4 ножках + мачта; AtlasBooster/Sustainer* → пьедестал + башня; TitanStage1 → пьедестал, эректор, башня;
SaturnSIC → ML 49×41 + LUT 120 м с 9 стрелами. Бетон строит C# (коробки), сталь — `Models/Pad_*.fbx` (10 шт., 4 слота).
При отрыве (`releaseT` от Landed→Flying): фермы и мачты откидываются (Tilt), стрелы башен уходят вбок (Swing, со сдвигом
по ярусам). Длина стрелы = расстояние шарнира до оси − радиус секции на её высоте − 0,3; выше верха стека стрел нет.
Не проверено в Play: анимация отвода, посадка стрелы на корпус. Константы Blender↔C# парные (см. комментарии).

## Детализация и кеш текстур (03.10.2026, `Game/DetailSettings.cs`, `Game/TextureCache.cs`)
Esc → Графика → «Детализация»: Низкая/Средняя/Высокая/Ультра (по умолчанию Высокая, PlayerPrefs `kare.detail.level`).
Перестраивает тела сразу (`BodyRenderer.ApplyDetail`), миссия не сбрасывается. Земля 1024…8192, облака 1024…8192,
Луна/Марс/огни 512…4096, сетка сфер и облаков, точек орбиты на карте 128…1024. Орбиты карты сэмплируются по истинной
аномалии (гладкий перицентр). Текстуры жмутся в DXT5 и кешируются на диск: первый проход уровня долгий (Ультра ~70 с),
дальше секунды. Облака: рваный край + внутренняя фактура (`EarthSurface.Cloud`, октавы растут с размером).
Прожекторы стола ночью (4 мачты, `LitNits` держит экспозицию), бетонная площадка до мачт (`ApronMargin`).
