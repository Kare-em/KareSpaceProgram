## Conventions
- Frame P = ecliptic J2000 (right-handed, z — pole); Unity = P with SwapYZ. Vessel nose = +Y.
- `Vessel.Position` — relative to the `Body` center, non-rotating axes (and it is the part's CoM). `body.OrientationAt(t) * forward` = pole.
- `Throttle <= 0` shuts the engine down; a restart spends an ignition and may require ullage.
- Autopilots work only in physics; rails are limited by `Universe.WarpLimitTime`.
- Code comments in Russian, "why", with a §GDD reference. Numbers — constants, with the paired dependency noted in a comment.
- Alias `using Terrain = Kare.Space.Core.Terrain;` in the game layer (conflicts with `UnityEngine.Terrain`).
- Glowing things (flame) — emission only; shared `MaterialPropertyBlock` — `Clear()` before every renderer.
- Runtime HDRP materials are not validated — set keys (`_EMISSIVE_COLOR_MAP`, `_DETAIL_MAP`) by hand.
- Camera near 1 / far 1e7, bodies in a "shell" (otherwise shadows vanish) — `docs/pitfalls-render.md`.
- File editing: Python script from a file, `newline=''` (CRLF); do not use `perl -i` on Cyrillic.
- Generate textures as atlases; downloading NASA textures — only with the user's explicit consent.
